# Go2Viral — الموقع + لوحة التحكم

موقع Next.js 16 شغال على **Supabase** (قاعدة البيانات، تسجيل الدخول، رفع الملفات) و**Vercel** (الاستضافة والتحليلات).
كل محتوى الموقع بيتعدل من لوحة التحكم على `/admin`، وبالعربي والإنجليزي.

---

## التشغيل لأول مرة (حوالي 20 دقيقة)

### 1) Supabase
1. اعمل مشروع جديد على supabase.com.
2. افتح **SQL Editor** وشغّل الملفات دي بالترتيب:
   - `supabase/schema.sql` (الجداول والصلاحيات ومكان رفع الملفات)
   - `supabase/seed.sql` (محتوى الموقع المبدئي)
3. **Authentication → Users → Add user**: اعمل حسابك بإيميل وباسورد، وعلّم على *Auto confirm*.
4. ارجع **SQL Editor** وخلّي الحساب ده أدمن (غيّر الإيميل):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'you@go2viral.co';
   ```
5. **Authentication → Sign In / Providers**: اقفل *Allow new users to sign up*، عشان محدش يعمل حساب غيرك.
6. **Project Settings → API**: انسخ `Project URL` و `anon / publishable key`.

### 2) GitHub + Vercel
1. ارفع الفولدر ده على ريبو جديد في GitHub.
2. في Vercel: **Add New → Project** واختار الريبو.
3. ضيف الـ Environment Variables دي (موجودة في `.env.example`):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `NEXT_PUBLIC_SITE_URL` (الدومين النهائي، مثال `https://go2viral.co`)
4. Deploy. بعدها من **Analytics** في مشروع Vercel اعمل Enable.
5. **Settings → Domains**: اربط الدومين بتاعكم.

### 3) على جهازك (للتطوير في Antigravity)
```bash
npm install
cp .env.example .env.local   # وحط فيه نفس القيم
npm run dev                  # http://localhost:3000
```

## لوحة التحكم `/admin`

| الصفحة | بتعمل إيه |
|---|---|
| نظرة عامة | الزيارات، الزوار، ضغطات الواتساب والحجز، الطلبات، أكتر شغل اتفتح، مصادر الزيارات، الأجهزة والدول |
| الصفحات والسكاشن | تعمل صفحات جديدة (مثلاً `/ar/doctors`)، وتضيف وتمسح وترتب وتخبي أي سكشن، وتعدّل محتواه بالعربي والإنجليزي |
| جوه أي سكشن شغل | تضيف **صفحة لايف** (بتتعرض شغالة جوه موبايل، وفيها زرار «افحص» يتأكد إنها تنفع وبيجيب صورتها)، أو **سكرين شوت**، أو **فيديو** (رفع أو لينك يوتيوب/تيك توك/إنستجرام/فيميو)، أو **لينك** |
| الدكاترة | الكروت المتفرّدة: الاسم، التخصص، صورة صغيرة، صورة/فيديو جوه الكارت، اللون |
| التخصصات | الفلاتر واختيارات الفورم |
| الطلبات | كل اللي بعتوا الفورم، مع حالة المتابعة والملاحظات وزرار واتساب وتنزيل Excel |
| مكتبة الميديا | كل الصور والفيديوهات، والصور بتتضغط لوحدها قبل الرفع |
| الإعدادات | اللوجو، لون البراند، رقم الواتساب، السوشيال، الشريط المتحرك، SEO |

أي حفظ في اللوحة بيحدّث الموقع على طول.

### أنواع السكاشن المتاحة
هيرو، كروت الدكاترة، الخدمات، عرض الشغل (موبايلات)، فيديوهات، جاليري، الأرقام والنتايج، خطوات الشغل، نص حر، بانر دعوة، التواصل.

## ملاحظات مهمة
- **الصفحات اللايف:** مواقع كتير بتمنع إنها تتعرض جوه فريم. زرار «افحص» بيقولك قبل ما تنشر، ولو ممنوعة الموقع بيعرض السكرين شوت وبيفتح الصفحة في تاب جديد.
- **الفيديوهات الكبيرة:** Supabase ليه حد لحجم الملف حسب الخطة. الريلز القصيرة ارفعها عادي، والفيديوهات الطويلة حطها لينك يوتيوب.
- **الأمان:** الزوار يقدروا يقروا المحتوى المنشور ويبعتوا الفورم بس. التعديل ورؤية الطلبات والإحصائيات للأدمن بس (Row Level Security).
- **seed.sql:** لو شغلته تاني بيرجّع سكاشن الصفحة الرئيسية للأصل. ماتشغلوش بعد ما تبدأ تعدّل.

## هيكل المشروع
```
supabase/          schema.sql + seed.sql
src/proxy.ts       تحويل / لـ /ar وحماية /admin
src/lib/           الأنواع، الترجمة، جلب البيانات، تعريف السكاشن (sections.ts)
src/components/site/     مكونات الموقع (كل سكشن في sections/)
src/components/admin/    مكونات لوحة التحكم
src/app/(site)/[locale]/ صفحات الموقع
src/app/(admin)/admin/   لوحة التحكم
src/app/api/       الفورم، التحليلات، التحديث، فحص الصفحات اللايف
design/prototype.html    النموذج الأصلي للتصميم
```
